# 🔧 AutomationProject

This is a **demo project** created for practicing test automation on a sample test website. 

Target website: *Practice Test Automation Site* (public demo)

## Test Cases Included

The demo includes **two test cases** related to the login functionality:

1. **Valid Login Test**
   - Enters correct username and password
   - Asserts successful login behavior

2. **Invalid Login Test**
   - Enters incorrect credentials
